## 5. 纪律提醒（本轮踩过的，逐条有代价）

1. **门禁非 0 就不要提交**。本轮我曾让脚本在 `check-depth` 红的情况下继续 commit+push，导致 CI gate 红、主分支一度不可用（`9bd1ed6` → 已由 `5e7eb4e` 修复）。脚本里必须 `if ($code -ne 0) { exit 1 }`。
2. **覆盖率回退不要放宽阈值**。正确解法是把不可测的 `main()` 逻辑抽成函数再测（`loadAccountsAndPool` 就是这么回到 72.7% 的）。
3. **变异核验只在 `%TEMP%` 副本里做**（L-2 硬规则），且**副本必须与待测代码同源**——未提交的代码在旧克隆里验证会得到 `build failed`（我第一次就踩了）。
4. **`git add` 的路径必须全部存在**：一个不存在的路径会让整条 add 中止，于是「什么都没提交」（本轮踩到一次）。
5. **先验证出口，再下结论**：`st.status` 我以为进标准 log，实际走 `chatLogOut`（`fmt.Fprintf`）。差点把真缺口判成等价变异。
6. **`usage.Recorder` 没 `Start()` 就不要 `Stop()`**：会永久阻塞（测试挂死过一次）。
7. **否定性断言要穷尽**（AGENTS.md / L-15）：本轮我写过「只影响 stderr」这种不完整结论，后来自己推翻。
