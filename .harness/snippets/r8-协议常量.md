# 代码块：R8 协议常量（出站报文的域名 / UA / Origin）

唯一来源：`internal/upstream/protocol.go`。守门测试：`protocol_r8_test.go`（把字面值钉死）。

## 规则

出站报文里的**任何**字符串——域名、UA、Origin/Referer、协议字段名——都只能从
`internal/upstream` 取，**禁止**在别的包再写一份字面量。

```go
// ✅ 正确
const clientUA = upstream.CLIUserAgent
const origin   = upstream.OriginRefererCN

// ❌ 错误：字面量散落即漂移入口（改一处忘一处 = 风控特征变化，且不报错）
const clientUA = "CLI/2.63.2 CodeBuddy/2.63.2"
```

## 现有常量

| 常量 | 值 | 用途 |
|---|---|---|
| `LoginBaseCN` | `https://copilot.tencent.com` | 设备授权 CN 域 |
| `LoginBaseGlobal` | `https://www.workbuddy.ai` | 设备授权国际版 |
| `OriginRefererCN` | `https://www.codebuddy.cn` | 出站 Origin/Referer（CN） |
| `OriginRefererGlobal` | `https://www.workbuddy.ai` | 出站 Origin/Referer（国际版） |
| `CLIUserAgent` | `CLI/2.63.2 CodeBuddy/2.63.2` | 登录/CLI 面 UA |
| `DefaultBillingBaseCN` | `https://www.codebuddy.cn` | 计费域 CN 默认 |
| `DefaultBillingBaseGlobal` | `https://www.workbuddy.ai` | 计费域国际版默认 |

注意 `OriginRefererCN` 与 `DefaultBillingBaseCN` **字面相同但语义不同**（一个是头，一个是请求目标域），
不要因为"看着一样"就合并。

## 升级版本的正确流程（有意的摩擦）

1. 只改 `protocol.go` 的字面量；
2. 改 `protocol_r8_test.go` 的期望值（**必须**——这是让改动可见）；
3. 跑真实账号冒烟（`python scripts/yg-regression-test.py`）——上游协议改动不可只靠单测。

## 已消灭的重复（2026-11-02）

`CLI/2.63.2 CodeBuddy/2.63.2` 曾在三处各一份（`models_fetch.go`、`panel/login.go`、
`cmd/login/main.go`）；两个 Origin 与两个登录基址在 `panel/login.go` 与 `cmd/login/main.go` 各一份；
两个计费基址在 `cmd/credit/main.go` 与 `upstream/client.go` 各一份。全部改为引用单一来源，
值一字未动（R8 要求的是"不改名"，不是"不许重构"）。
