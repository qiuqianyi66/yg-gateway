# L-24 DOM insertBefore 的参照节点必须是直接子节点

**一句话**：`parent.insertBefore(el, ref)` 若 `ref` 不是 `parent` 的**直接子节点**，抛
`NotFoundError`，同步栈整条中断——页面表现是「部分区块加载失败」，而不是「这一块没渲染」。

## 场景（2026-11-04，Seen 1）

游戏化层 `renderStreak()` / `renderAchievements()` 把动态条插入 `#view-taskscenter`，
参照点用 `#qProg`。但 `#qProg` 实际在 `.box` 内，是宿主的**孙层**——浏览器抛
`NotFoundError: ...is not a child of this node`。这条异常发生在 `start()` 里，导致
后续 `renderAchievements()`、`checkAuthGate()` 全部没跑，用户观感是「整页好多东西加载不出来」。

## 根因

- 凭 id 查找就当「可以直接插到宿主前」——没核对 `ref.parentNode === host`。
- 已有的 node smoke 用 inert Proxy 桩 DOM，所有调用被吞掉，对「参数语义错」完全盲目，
  测试全绿但浏览器必崩。

## 规则

1. 动态插入参照已有节点时，一律用 `ref.parentNode.insertBefore(el, ref)`（null 才 appendChild）；
2. 前端测试 DOM 桩必须实现**真实父子约束**（非直接子节点 insertBefore 抛错），
   不能只用万能 Proxy 吞一切。

## 防法

- 机器检查（已落地）：`TestGamifyStripsInsertIntoNestedContainer`——带真实父子约束的
  FakeNode 桩，旧写法实测 FAIL、修复后 PASS（牙齿已验证）。
